# Engine sources (GPL-3.0 compliance)

ManaTTS bundles unmodified third-party speech-engine binaries/data:

1. **piper** (native binary + libpiper_phonemize + libespeak-ng), v1.2.0
   - Upstream: https://github.com/rhasspy/piper (archived) / successor https://github.com/OHF-Voice/piper1-gpl
   - License: GPL-3.0 (see GPL-3.0.txt). Corresponding source is available
     at the upstream repositories above.
2. **espeak-ng-data** (phonemizer data bundled with piper)
   - Upstream: https://github.com/espeak-ng/espeak-ng
   - License: GPL-3.0 (see GPL-3.0.txt).

The Mana voice model itself is MIT-licensed and unaffected.
